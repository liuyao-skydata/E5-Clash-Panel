# 发布指南

这个文件夹已经是一个可以直接 `git push` 的仓库雏形。两种发布方式，任选一种。

---

## 方式一：双击「一键上传.cmd」（推荐）

1. 先在 GitHub 生成一个 Token：
   - 打开 <https://github.com/settings/tokens/new?scopes=repo&description=E5-Clash-Panel>
   - 勾上 **repo**（classic）；或者用 fine-grained token，给 **Contents: Read and write** + **Administration: Read and write**
   - 有效期随便，生成后复制那串 `ghp_...`（只显示一次）
2. 双击本文件夹里的 **`一键上传.cmd`**
3. 按提示把 Token 粘进去（不回显）→ 等它跑完

脚本会依次做：

```
git init / add / commit
→ 调 GitHub API 建仓库（已存在就跳过）
→ 推送到 main
→ 建 Release  v1.0.0
→ 把 release/ 里三个文件传成附件
```

结束时会打印仓库地址和「别人怎么装」的三行命令。

**常用参数**（命令行方式）：

```powershell
.\tools\publish-github.ps1 -Token ghp_xxx          # 直接给 token，不交互
.\tools\publish-github.ps1 -Repo e5-clash-panel    # 改仓库名
.\tools\publish-github.ps1 -Private                # 建私有仓库
.\tools\publish-github.ps1 -NoRelease              # 只推代码，不发 Release
```

Token 只在内存里用，不会写进 `.git/config`，也不会落盘。

## 方式二：手动（不用脚本）

```bash
cd "E:\桌面\E5-Clash-Panel"
git init -b main
git add -A
git commit -m "E5 信息屏 Clash 面板 v1.0.0"

# 在 GitHub 网页上新建空仓库（不要勾 README/.gitignore）
git remote add origin https://github.com/liuyao-skydata/E5-Clash-Panel.git
git push -u origin main
```

然后网页上 **Releases → Draft a new release**：

- Tag：`v1.0.0`
- 标题：`v1.0.0 + Clash面板`
- 说明：可以直接抄 `README.md` 里的「安装」段
- 附件：把 `release/` 里三个文件拖进去（`e5-panel-install.sh`、`e5-panel-1.0.0.tar.gz`、`SHA256SUMS`）

## 发布前检查

| 检查项 | 说明 |
|---|---|
| `README.md` 截图 | 用的是 `docs/screenshots/clash-panel-demo.png`（设备实拍，**已脱敏**：裁掉配置/IP/额度区，节点名改为示例01） |
| `release/` 三个文件 | 和 `SHA256SUMS` 对得上：`cd release && sha256sum -c SHA256SUMS` |
| 换行 | `.gitattributes` 已把 `release/e5-panel-install.sh` 标成 binary，git 不会动它的换行 |
| 许可 | `LICENSE`（本仓库 MIT）+ `NOTICE`（说明载荷里含 Enceka 的 MIT 信息屏、twemoji 国旗） |
| 仓库可见性 | 默认**公开**。想先私有：`-Private`，验证没问题再在 Settings 里转公开 |
