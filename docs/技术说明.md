# 技术说明

给想看实现的人。设备上的信息屏是一个跑在 `cage` + `cog`（WebKit）里的本地网页，
数据由同机的 `uhttpd`（`127.0.0.1:8088`）通过 `api.uc` 提供。Clash 面板就是在这个网页里
新加的一页（第 10 页，`data-title="clash_mon"`）。

## 数据从哪来

```
cog (页面 app.js)  ──fetch /api/status──▶  uhttpd :8088 ──▶ api.uc
                                                            │
                                        ┌───────────────────┴────────────────────┐
                                        │ clash_status()：读 /tmp 缓存，缺就 spawn │
                                        ▼                                        ▼
                         /usr/libexec/e5-clash-status                     uci openclash + curl 127.0.0.1:9090
                         （ucode，秒级）                                    （Clash 外部控制器）
```

| 前端调用 | 后端 | 采集方式 | 缓存 |
|---|---|---|---|
| `GET /api/status` | `api.uc` → `e5-clash-status`（默认态） | `pidof clash` 判运行；uci 取端口/配置；`curl 127.0.0.1:9090/proxies` 取当前节点 | 3 s（`/tmp/run/.../clash.json`） |
| `POST /api/clash-net` | `e5-clash-status net` | 对四站各测一次 `delay`（**经节点**，不是设备直连）：百度 / 网易云 / GitHub / YouTube，超时 4 s | 10 s（`/tmp/e5-clash-net.json`，每站保留 24 点历史） |
| `POST /api/clash-ip` | `e5-clash-status ip` | 四家查询：PConline / IPIP.NET（直连 → 本机公网 IP）、IP.SB / IPIFY（走节点 → 落地 IP）。PConline 是 GBK，原始字节 base64 回前端用 `TextDecoder('gbk')` 解 | 120 s（`/tmp/e5-clash-ip.json`） |
| `GET /api/clash-sub`（并入 status） | `e5-clash-status sub` | 订阅地址取自 `uci openclash.@config_subscribe[n].address`，`curl -K` 带上 UA，解析 `subscription-userinfo` 头 | 900 s |
| `POST /api/openclash {on}` | `api.uc` | **先写 `uci openclash.config.enable`**（LuCI 读的是它，不是进程），再 `/etc/init.d/openclash start\|stop` | 清缓存 |
| `POST /api/clash-config {name}` | `api.uc` | 校验 `^[A-Za-z0-9._-]{1,64}\.ya?ml$` + 文件存在 → uci `config_path` → 内核在跑才 restart | 清缓存 |
| 切节点 | `PUT 127.0.0.1:9090/proxies/<组>` | 直连 Clash 控制器，不重启内核，立即生效 | — |

## 前端结构

- `app.js`：`P.clash_mon = 9`。`renderClash()` 画状态行、四站卡、节点卡、配置卡、IP 卡；
  `sparkSVG()` 出 24 点折线（`preserveAspectRatio=none` + `vector-effect`，宽度拉伸不变形）；
  按键模型和 Lucky 页共用：两次 OK 确认、光标保持、返回取消。
- `mobile.js`：`titles[9]` 决定手机/窄屏头部标题与「全部页面」宫格里的名字（=「Clash面板」）。
- `style.css`：整页节奏集中在 `section[data-title="clash_mon"]` 一段——组间 7px、标签与卡片 4px，
  408px 可视区刚好铺满；三颗按钮统一 62×28 靠右。
- 国旗：`nname()` 把 `🇯🇵` 这类区域旗帜组合换成本地 `flags/<iso>.svg`（设备没有 emoji 字体）。

## 安装包为什么是自解压脚本

镜像（OpenWrt 25.12 / armsr armv8）用的是 **apk v3**，设备上的 `apk` 3.0.5 没有 `mkpkg`，
本地也没有 v3 签名链。负载全是纯文件（网页 + ucode + init 脚本 + 一个 TZif），
所以做成「脚本 + 内嵌 tar.gz」：

```
#!/bin/sh
... 安装逻辑（备份 → 解包 → 起服务）...
__PAYLOAD__
<gzip 二进制>
```

- 构建时把 `__PAYLOAD__` 后的起始行号写死成 `SKIP=NNN`（`installer/build.py`）；
- 运行时 `tail -n +$SKIP "$0" | tar -xzf - -C /`，取之前先 `sha256sum` 比对；
- 备份：逐路径 `tar czf` 到 `/root/e5-panel-backups/<时间>/`，`--restore` 就是反向解包。

**坑**：不要对成品 `.sh` 跑 `sed -i 's/\r$//'`——gzip 是二进制，按行处理会抹掉 `0x0D`，
SHA-256 必然对不上。`.gitattributes` 里已把它标成 `binary`。

## 文件清单

| 路径 | 归属 |
|---|---|
| `/usr/share/e5-infoscreen/{www,api.uc,settings.uc,updates.uc,default.config,xkb}` | 上游 info screen（MIT, Enceka），本仓库改过 `www/*` 与 `api.uc` |
| `/usr/libexec/e5-clash-status` | 本仓库新增 |
| `/usr/libexec/e5-infoscreen/session` | 上游，补了 `TZ` 导出 |
| `/etc/init.d/e5-infoscreen` | 上游（procd：seatd + uhttpd:8088 + cog） |
| `/www/luci-static/resources/view/e5-infoscreen/*`、`menu.d`、`acl.d` | 上游 LuCI 设置页 |
| `/usr/share/zoneinfo/Asia/Shanghai` | 本仓库新增（115 B TZif） |

不打包、不覆盖：`/etc/e5-infoscreen/`（壁纸、插件）、`/etc/config/e5-infoscreen`（用户设置）、OpenClash 配置。

## 时区那件事

镜像里没有 tzdata（`/usr/share/zoneinfo` 空的，`/etc/localtime → /tmp/localtime` 断链）。
glibc 读 `/etc/TZ`（`CST-8`）没问题，但 WebKit 的 ICU 只认 tz 数据库文件，于是浏览器退化到 UTC，
页面时钟差 8 小时。修法：

1. 手写一个 115 字节的 TZif 放到 `/usr/share/zoneinfo/Asia/Shanghai`；
2. `session` 里 `uci get system.@system[0].zonename`，文件在就 `export TZ=Asia/Shanghai`；
3. `/etc/init.d/system` 会把它软链到 `/tmp/localtime`。

## 重新打包

```bash
cd installer
python build.py    # install-header.sh + ../release/e5-panel-<ver>.tar.gz → ../release/e5-panel-install.sh
cd ../release && sha256sum e5-panel-install.sh e5-panel-*.tar.gz > SHA256SUMS
```

载荷是怎么从设备上取出来的（排除用户数据）：

```sh
cd / && tar -czf /tmp/e5-panel.tar.gz -X exclude.txt -T list.txt
# list.txt:    usr/share/e5-infoscreen usr/libexec/e5-infoscreen usr/libexec/e5-clash-status
#              etc/init.d/e5-infoscreen www/luci-static/resources/view/e5-infoscreen
#              usr/share/luci/menu.d/luci-app-e5-infoscreen.json usr/share/rpcd/acl.d/luci-app-e5-infoscreen.json
#              usr/share/zoneinfo/Asia/Shanghai
# exclude.txt: usr/share/e5-infoscreen/www/plugins 与 .../plugins/*   ← 服务启动时由 plugin link 重建
```
